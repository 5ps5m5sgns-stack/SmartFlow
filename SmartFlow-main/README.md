# SmartFlow 🚦

> Des feux qui pensent. Pour une ville qui respire.

Site vitrine du projet **SmartFlow** : un logiciel open-source qui adapte les feux de signalisation en temps réel grâce à l'IA — moins d'arrêts inutiles, moins de CO₂, plus de fluidité urbaine.

🏆 Lauréat de la **Bourse Jeune 2025** (meilleur projet environnemental parmi 200+ candidatures).

🌐 **Site en ligne :** [smartflowprojet.com](https://smartflowprojet.com)

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Accueil — hero 3D animé (moteur de projection perspective maison, 0 dépendance) |
| `solution.html` | La solution en 5 étapes (détecter, prédire, décider, connecter, apprendre) |
| `projet.html` | Mission, valeurs et reconnaissance du projet |
| `demo.html` | Simulation interactive : feux classiques vs SmartFlow sur le même carrefour |
| `contact.html` | Formulaire de contact (Formspree) |
| `404.html` | Page d'erreur personnalisée |

## Stack

- HTML/CSS/JS vanilla, chaque page est autonome (styles et scripts inline)
- Aucun framework, une seule lib externe : [GSAP](https://gsap.com) (animations de scroll, chargée en async)
- Hébergement : GitHub Pages
- Zéro cookie de traçage, zéro analytics

## Développement

Aucun build : ouvrir `index.html` dans un navigateur, c'est tout.
